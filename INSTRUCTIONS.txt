ОБНОВЛЕНИЕ СУЩЕСТВУЮЩЕГО hh_assistant_bot2 (не новый проект)

Заменяются шесть существующих файлов. Настоящий .env НЕ заменять!

1. Закройте бота в терминале Ctrl+C. Сохраните копии трёх старых файлов.
2. Замените knowledge_base.py, yandex_assistant.py, requirements.txt,
   .env.example, .gitignore и README.md
   файлами из этого комплекта. Не перезаписывайте main.py, bot_max.py и .env:
   в них есть ваши локальные исправления SSL MAX.
3. В main.py найдите блок:
       # Режим обновления базы знаний
       if args.update_kb:
   НИЖЕ БЛОКА (после `return` и ДО `if args.cli:`) вставьте:
       # Автоматическое обновление базы знаний каждые 6 часов.
       kb.start_auto_updates(interval_hours=6)
   Важно: строка должна иметь отступ 4 пробела (внутри main).
4. В локальном .env найдите YC_MODEL и поменяйте на:
       YC_MODEL=yandexgpt-5.1
   Также настройте YC_API_KEY= и YC_FOLDER_ID= (сами значения не присылайте).
   YC_ASSISTANT_ID может оставаться пустым; Responses API его не использует.
5. .env.example и README.md уже обновлены в комплекте. Никаких
   настоящих токенов и паролей в них не содержится.
6. Установите:
       python -m pip install -r requirements.txt
7. Проверка синтаксиса:
       python -m py_compile main.py bot_max.py knowledge_base.py yandex_assistant.py
8. Запуск:
       python main.py --max

Важно: фоновое обновление выполняется только пока запущен Python.
Ответ YandexGPT требует действующий API-ключ, доступ к модели и платёжный аккаунт Yandex Cloud.
При недоступности Yandex Cloud бот переключается на локальную выдачу найденных документов.
